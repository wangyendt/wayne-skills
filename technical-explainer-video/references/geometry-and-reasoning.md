# 几何与计算如何讲清楚

## 先画依赖，再画画面

为每个指标列出：输入与来源 → 坐标/表示 → 取点或取样 → 单项计算 → 聚合 → 输出含义。确实涉及验收时才追加门限和复测。先教前置概念，避免在后半段补解释前半段已经使用的量。

- 说明计算用了全部数据、边界点、中心区域还是有效子集；选择规则应可复现。可见的辅助点与参与计算的点用颜色或亮度区分。
- 平均值、绝对值、最大值、标准差、分位数有不同含义。演示运算顺序，避免带符号量抵消后误读为没有误差。
- 单位转换、归一化、投影、拟合和反求分别显示，不用一条箭头跳过用户正在困惑的步骤。
- 来源记录在工程中；示例数据与实测数据分开。示例结果由同一份参数计算驱动，显示时才舍入。

## 几何动作与旁白配对

1. 给出坐标原点、正方向、单位和观察视角。区分观察动画的相机与题目中的相机/对象。
2. 选中当前点，突出相关起点、终点、线段或平面；放大局部时保留方向参照。
3. 从对象到投影平面作垂线，保留端点对应；切换 2D 后沿用同一颜色、标签、比例和正方向。
4. 显示实际用于计算的边、角弧、法线或残差，再显示公式和数值。
5. 逐项完成后再显示集合统计或最终判断，不让全量线条淹没当前步骤。

同一物理量跨 2D/3D 视图必须来自同一计算结果。非等比例显示须注明，且不能用失真的屏幕夹角代表真实角度。透明平面避免挡住重点。

## 信息是否足够

一个总量可能对应多个分量组合。演示反求前，检查是否还需要方向、约束或额外测量。可画保持总量不变、分量持续变化的例子，让观众看到缺失的信息。

正交投影通常通过保留目标平面内的分量、清零法向分量得到。之后再求该平面内的角；分量角不一定相加等于总角。明确角度相对哪根轴、符号如何定义、输出是弧度还是度，以及零向量或分母为零时的处理。

几何角、欧拉角、法线倾角、点线夹角分别定义。只有推导与坐标约定相符时才使用同一术语或等式。近似关系标明适用条件，不能用小角近似冒充精确恒等式。

## 公式展示

用 LaTeX 渲染器处理数学内容。变量先出现在图上，再出现于公式；公式按推导分行，避免一次展示整页。长式分步显示，不缩小到难读。中文字、解释性标签单独绘制。

标清物理量、索引、单位与取值域。使用实际计算值检查代入、符号、归一化、四舍五入和边界。几何、公式、字幕与旁白指向同一步骤。
